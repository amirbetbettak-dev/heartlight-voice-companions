# Roadmap — همدم (empathetic AI companion)

- [x] Backend: Google sign-in, tables for settings / messages / memory
- [x] Four personas (2 female, 2 male) with distinct voices and tones
- [x] Dark home screen with animated robot face (eyes + mouth react to listening/speaking/emotion)
- [x] Live voice conversation (Persian), seeded with memory + recent history, transcripts saved
- [x] Memory: AI-maintained notes about the user
- [x] Mobile-first responsive + installable (manifest, icons)
- [ ] Guest sign-in button (no Google needed)
- [ ] Phone number + SMS code sign-in screen (needs an SMS sending service turned on in Auth settings)
- [ ] Minimal, classy landing with modern AI logo (no long descriptions); face lively right after sign-in
- [ ] Organized settings: separate Persona & voice menu (4 personas), separate Memory page, history page
- [ ] Separate chat history per persona + "New conversation"
- [ ] Persona tones: women more playful/witty/warm, men witty/charismatic; voice identity fixed per persona
- [ ] Natural, non-cliché openings; rich vocabulary; learn & reuse the user's own words
- [ ] Interruptions: pause, listen, answer, then resume the unfinished thought
- [ ] Verify end-to-end (sign in, text chat, voice call) — waits on a real signed-in test with a microphone
