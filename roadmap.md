# Roadmap — همدم (empathetic AI companion)

- [x] Backend: Google sign-in, tables for settings / messages / memory
- [x] Four personas (2 female, 2 male) with distinct voices and tones
- [x] Dark home screen with animated robot face (eyes + mouth react to listening/speaking/emotion)
- [x] Live voice conversation (Persian), seeded with memory + recent history, transcripts saved
- [x] Memory: AI-maintained notes about the user
- [x] Mobile-first responsive + installable (manifest, icons)
- [x] Guest sign-in button (no Google needed)
- [x] Phone number + SMS code sign-in screen
- [ ] Turn on SMS sending for phone sign-in — waits on an SMS service account (Iranian numbers need a local SMS provider)
- [x] Minimal, classy landing with modern AI logo (no long descriptions); face lively right after sign-in
- [x] Organized settings: separate Persona & voice menu (4 personas), separate Memory page, history page
- [x] Separate chat history per persona + "New conversation"
- [x] Persona tones: women more playful/witty/warm, men witty/charismatic; voice identity fixed per persona
- [x] Natural, non-cliché openings; rich vocabulary; learn & reuse the user's own words
- [x] Interruptions: pause, listen, answer, then resume the unfinished thought
- [ ] Verify end-to-end (sign in, text chat, voice call) — waits on AI credits (replies currently fail: credits used up) and a real microphone test
- [x] Android APK via Capacitor, built automatically in GitHub Actions (downloadable from the Actions run)
- [x] Optional own AI key (OpenRouter / Groq / OpenAI) for text chat and memory
- [ ] Add an own AI key — waits on the user providing one (OpenRouter, Groq or OpenAI)
- [ ] First APK build on GitHub — waits on the project being connected to GitHub
- [x] Text chat: no false "reply incomplete" error after a full reply; natural Tehrani Persian instructions; free backup models when the chosen one is busy
- [x] Free voice mode with the browser's speech recognition + speech voice, connected to the same chat (no Lovable credits)
- [ ] Real-microphone test of the free voice mode on a phone — needs the user's device
- [ ] Personal installable app with no Lovable traces: remove the Google button (it opens an outside Lovable page), make guest sign-in the default and fast, hide the Lovable badge
- [ ] Much stronger warm Tehrani colloquial Persian: slang/phrase dictionary + sample chats per persona, ban bookish/Afghan/machine-translated wording; best free OpenRouter model for colloquial Persian
- [ ] Independent Android package id (ir.hamdam.companion) and updated GitHub APK build
