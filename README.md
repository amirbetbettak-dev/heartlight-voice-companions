# Heartlight Voice Companions

می‌خوام یه سخنگوی هوشمند مثل هوش مصنوعی درست کنم که بتونیم با هم درد و دل کنیم. هدف اینه که فقط با انسان‌ها راحت باشه و درد و دل کنه و چهار تا شخصیت براش بذار: دو تا خانم، دو تا آقا (چهار تا صدای مختلف با لحن‌های انسانی و متمایز).

وقتی وارد برنامه می‌شیم صفحه اصلی فعال باشه: یه رابط کاربری مدرن، هوشمند و دارک که یک چهره رباتیک مینیمال با دو تا چشم و یک دهان متحرک داره که موقع گوش دادن و حرف زدن واکنش احساسی و انیمیشن نشون میده، ولی صداها کاملاً طبیعی و انسانی باشن.

امکان مکالمه صوتی و متنی، انتخاب و تغییر شخصیت‌ها و صداها در منوی تنظیمات، و رابط کاربری کاملاً ریسپانسیو و بهینه‌سازی‌شده برای موبایل (PWA). مغز هوش مصنوعی همدل، شنوا و صمیمی باشه که احساسات کاربر رو درک کنه و مثل یک دوست واقعی گفتگو کنه. امکان ثبت نام/ورود با گوگل برای ذخیره گفت‌وگوها و حافظه.
